## 🔬 Featured Projects

### ⚡ [IMU-Based Human Activity Recognition (HAR) System on Edge](https://github.com/abhaanisha)
- **Stack**: `TinyML` `Arduino Nicla Vision` `3-Axis Accelerometer & Gyroscope` `Scikit-Learn` `Python`
- Engineered an end-to-end TinyML pipeline on **Arduino Nicla Vision** classifying 12 distinct human activities (eating, pick-and-place, jogging, cycling).
- Captured **120,000+ IMU samples** at 50 Hz; extracted 72-dimensional statistical feature vectors (Mean, RMS, Energy) over 20-sample sliding windows.
- Deployed real-time on-device inference with **99.43% classification accuracy** for high-dynamic activities.

### 🌿 [Hybrid CNN-ViT Model for Plant Disease Classification](https://github.com/abhaanisha)
- **Stack**: `PyTorch` `Vision Transformers (ViT)` `CNNs` `Transfer Learning` `Computer Vision`
- Developed a hybrid deep learning architecture coupling Convolutional Neural Networks (local feature extraction) with Vision Transformers (long-range dependency modeling).
- Attained **98.23% test accuracy** across 21,000 images on the Tomato Leaf Disease dataset.
- Slashed test loss from 0.3182 to **0.0956** and elevated F1 scores from 0.8842 to **0.9819** vs baseline CNN models. Published at **CVIP 2023 (Springer Nature)**.

### 🛍️ [E-Commerce Recommendation System using Truncated SVD-SGD](https://github.com/abhaanisha)
- **Stack**: `Python` `Matrix Factorization` `Truncated SVD` `SGD` `Collaborative Filtering`
- Formulated a model-based recommendation engine decomposing a sparse utility matrix of 50,000 user-product interactions into latent feature representations.
- Executed item-to-item correlation analysis generating targeted product recommendations with a **Pearson correlation coefficient > 0.90** across 2,845 beauty products.

### 🔐 [Hybrid Encrypted Reversible Data Hiding (HERDH)](https://github.com/abhaanisha)
- **Stack**: `Wavelet Transform` `Steganography` `Information Security` `Digital Image Processing`
- Master's Thesis: Developed a hybrid reversible data-hiding algorithm utilizing wavelet-domain transformation.
- Attained **>50 dB PSNR** and a **72% improvement** in visual fidelity over existing techniques. Published in **IJCSNS 2017**.
